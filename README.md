# Negocios del Campo

Sitio web estático para presentar a Negocios del Campo, empresa de Paraguay. El diseño toma como referencia el enfoque visual de sitios agropecuarios B2B: fotografía protagonista, navegación sencilla, presentación de la empresa, áreas de trabajo y contacto. Es una propuesta original, no una copia del sitio de referencia.

## Ver el sitio

Abrí `index.html` en un navegador o publicá este repositorio con GitHub Pages.

## Antes de publicar

- Revisá los textos y reemplazá las áreas de trabajo de ejemplo por los productos y servicios reales de la empresa.
- Añadí teléfono, correo, dirección, redes sociales y logotipo oficiales cuando estén disponibles.
- El formulario de contacto es visual y no envía datos todavía. Conectalo a un servicio de formularios o a un backend.
- Las fotografías se cargan desde Unsplash; podés cambiarlas por imágenes propias.

El proyecto no requiere herramientas de compilación ni dependencias locales.
